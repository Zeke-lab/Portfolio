# Premium Personal Portfolio Website

This is a code bundle for Premium Personal Portfolio Website. The original project is available at https://www.figma.com/design/tACwL5elyONv313YOye9ui/Premium-Personal-Portfolio-Website.

## Running the project locally

Use npm in the backend and frontend folders separately.

### Backend

```bash
cd backend
npm install
npm run dev
```

To apply the database migration:

```bash
cd backend
npm run db:migrate
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Production build

```bash
cd frontend
npm run build
```
